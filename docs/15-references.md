## How the list was made

- A Node script read, on 15/11/2026, all `.md` files in `docs/` (00, 01, 02, 03, 04, 05, 06, 07, 08, 09, 10, 11, 12, 14, 16; this document and the glossary are left out) and in `pesquisa/bruto/` (tracks 01, 02, 03, 04, 05, 06, 07, 08, 09, 10, 11, 13, 14, 15, 16, 17, 18, 19) and extracted the URLs from Markdown links and the bare URLs in text, tables and code blocks. Track 19 (cross-check) was included because it was already in the folder at the time of the scan.
- There were 5723 URL occurrences, with 959 different spellings and **958 unique URLs** after removing duplicates. Two spellings count as the same URL when they differ only in `http` or `https`, `www.`, trailing slash or `#` anchor. The sum of the groups (958) matches the total of unique URLs (958).
- The title of each link is the link text most used in the documents, without the evidence labels ([OFFICIAL], [PAPER] and similar). When the URL appears only bare or with a label in place of the text, the title comes from the address itself (site and end of the path).
- The groups follow the domain and the type of the source. Besides the requested groups, there are two for sources that are not press: "Health, standards, universities and other institutions" (FDA, MedlinePlus, AAO, ISO, W3C and universities) and "Open data, code and licenses" (PhysioNet, Zenodo, GitHub, Freesound and Creative Commons). NASA repositories on GitHub stay in the NASA group; those of manufacturers, in manufacturers. The AEB page stays in other agencies, not in the Brazilian government.
- Addresses with `{TIPO}` or example dates are API query templates cited in the documents; they were kept as they are.
