ORBITA: responsive wireframes of screens M01 to M18

Medium-fidelity drawings for whoever runs the code in Lovable. The specification of each screen, the tokens and the done criteria are in docs/18-orbita-responsive-design.md. Demo data from docs/17, section 4: ISS EXP-01 mission, day 45, Astronaut 001. Values and texts aligned with docs/19, section 14. O2, pressure, protons and Kp come from the real ISS and NOAA recording of 11/15/2026 (badge "Real recorded"); the rest is simulated. Nothing blinks, nothing plays sound; every state has color, icon and word.
